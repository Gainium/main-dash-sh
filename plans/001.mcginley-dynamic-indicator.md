# 001. McGinley Dynamic indicator — main-dash-sh plan

Implements [specs/001.mcginley-dynamic-indicator.md](../specs/001.mcginley-dynamic-indicator.md).
Depends on `indicators`' `002.mcginley-dynamic-indicator` (math, published
separately) and `app-sh`'s `006.mcginley-dynamic-indicator` (the field
shapes this repo's catalog entry must match). Developed in parallel per
this being a demonstration of all three; the real dependency chain would
publish `indicators` first.

## Build order

1. `src/types/index.ts`:
   - `IndicatorEnum.mg = 'MG'` (no supporting enums needed — no bespoke
     fields, per spec §4).
2. `src/utils/tradingView/customIndicators.js`:
   - New `export const MG = (r, callback) => ({...})` study, modeled on
     `ATR`'s minimal single-input/single-plot template (input `in_0`
     length + hidden `id`, `callback(value, id)`), with `is_price_study`/
     `linkedToSeries` set like `EMA`/`WMA` (price overlay, unlike `ATR`'s
     separate pane) and the recursive formula hand-computed via
     `this._context.new_var(NaN)` + `.get(1)`/`.set(...)`, the same
     state-persistence idiom `LW` uses for its levels.
   - Register `MG(r, cb)` in the `loadCustomIndicators()` array, after `LW`.
3. `src/components/widgets/shared/TradingViewChart/indicatorStudyConfig.ts`:
   - `STUDY_NAME_MAP[IndicatorEnum.mg] = 'McGinley Dynamic'` — must equal
     the study's own `name`/`description` string (spec §3).
   - `buildInputs()` case: `case IndicatorEnum.mg: return { in_0:
     toNumber(indicator.length, 14) };` — mirrors `ATR`'s case exactly, no
     bespoke-field fallback (`ATR`'s `?? indicator.atrLength` doesn't apply
     — McGinley has no legacy bespoke field to fall back to).
4. `src/types/indicators/indicatorCatalog.ts`:
   - `INDICATOR_CATALOG[IndicatorEnum.mg]`: `label: 'McGinley Dynamic'`,
     `category: IndicatorCategories.Trend` (matches `ma`'s category — both
     are trend-following moving averages), `fields:` mirroring `ATR`'s
     list exactly (`indicatorLength`, `indicatorInterval`,
     `indicatorCondition` w/ `INDICATOR_CONDITION_OPTIONS`,
     `indicatorValue`, `keepConditionBarsField`) — **not** `ma`'s fields
     (spec §3).
   - `INDICATOR_DOCUMENTATION_URLS[IndicatorEnum.mg] = '/help/mcginley-dynamic'`
     — named dead link until the `content` repo PR (out of scope) lands,
     per spec §4.
5. `package.json` version bump (MINOR — new feature) + `CHANGELOG.md`
   entry, per this repo's `CLAUDE.md` release ceremony (required on every
   PR that changes user-visible behaviour).

## Contract decisions the spec left open (§3)

- **Template: `ATR`'s shape for input/plot/callback wiring, `LW`'s
  state-persistence idiom for the math itself.** Neither alone was a
  complete match; combined, they are (see spec §3 for the full reasoning).
- **Catalog fields mirror `ATR`, not `ma`.** Confirmed against `app-sh`'s
  spec §2 decision (no bespoke fields) — using `ma`'s field set would
  silently create settings `app-sh` never reads.
- **`STUDY_NAME_MAP` value = the study's own name, no `(Custom)` suffix**
  — matches `LW`'s precedent (a wholly custom, non-TradingView-builtin
  indicator), not `ATR`'s (a reimplementation of a real TradingView
  builtin).
